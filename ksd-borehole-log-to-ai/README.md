# KSD案件 ボーリング柱状図 PDF → Illustrator(.ai) 変換ツール

特別史跡加曽利貝塚新博物館（仮称）整備・運営事業 地盤調査（光貴基礎コンサルタント（株））の
ボーリング柱状図PDF（No.1〜No.8 の最終版8枚）を、Illustratorで編集可能な `.ai` に一括変換し、
変換前後をチェックするための一式。

処理の流れは3段構え：

| ステップ | 使うもの | 実行場所 | やること |
|---|---|---|---|
| Step 1-2 事前チェック | `preflight.py` | Python（どのOSでも可） | 8ファイルが揃っているか、ベクターPDFか、フォントは埋め込まれているか |
| Step 3 変換 | `pdf_to_ai.jsx` | Illustrator | PDFを開いて `.ai` で保存＋確認用PNG書き出し |
| Step 4 事後チェック | `verify_ai.py` | Python | 出力された `.ai` を元PDFと突き合わせ、文字欠落・文字化けを検出 |

## ⚠️ 未検証の部分

- `pdf_to_ai.jsx` と `run_on_windows.vbs` は **Illustrator実機での実行は未検証**（この環境に
  Illustratorが無いため）。構文チェックのみ実施済み。初回は1ファイルで試してから8枚流すこと。
- `preflight.py` / `verify_ai.py` は本番8枚に加えて、ダミーPDFで正常系・ファイル欠落・
  ファイル取り違え・スキャン画像PDF・未埋め込みフォント・文字欠落・文字化け・破損`.ai`の
  各ケースを確認済み。

## 必要なもの

- Adobe Illustrator（CC以降。Step 3のみ必要）
- Python 3.8以上（Step 1-2, 4）
- 対象PDFに使われている日本語フォント（詳細は「フォントの扱い」）

## セットアップ

```bash
pip install -r requirements.txt
```

外部通信は一切しない。`pypdf` だけで動く。

## 使い方

以下、PDFを置いたフォルダを `WORK` と書く（例:
`C:\Users\tsoma\Documents\KSD_地盤調査\柱状図_最終版`）。
`manifest.json` に書かれた8ファイルの名前どおりに `WORK` 直下へ置くこと。

### Step 1-2: 事前チェック

```bash
python preflight.py --dir "C:\Users\tsoma\Documents\KSD_地盤調査\柱状図_最終版"
```

- 8ファイルが揃っているか（名前違いがあれば「似た名前のファイル」として候補を出す）
- 1ページ構成か／用紙サイズ
- テキストが抽出できるベクターPDFか（スキャン画像PDFならここで `ERROR`）
- 使用フォントと埋め込みの有無
- PDF本文の「ボーリング名」「総掘進長」がファイル名・manifestと一致しているか
  （取り違え・途中版の混入を検出）

結果は画面と `WORK\reports\preflight_report.{json,md}` に出る。
`MISSING` / `ERROR` が1件でもあれば終了コード1を返すので、そこを潰してから Step 3 へ進む。

### Step 3: Illustratorで変換

1. Illustratorを起動する
2. **ファイル > スクリプト > その他のスクリプト...** で `pdf_to_ai.jsx` を選ぶ
3. フォルダ選択ダイアログで `WORK` を指定する

`WORK\ai\` に `[元ファイル名].ai` が、`WORK\ai\preview\` に確認用PNGが、
`WORK\ai\conversion_log_YYYYMMDD_HHMMSS.txt` にログが出る。ログには1ファイルごとに
アートボード数・テキスト数・パス数・**Illustrator上で実際に使われているフォント名**が残る。

コマンドから起動したい場合は `cscript //nologo run_on_windows.vbs`（未検証。上記の
メニュー実行が確実）。

`pdf_to_ai.jsx` の先頭 `CONFIG` で変えられる主なもの：

| 設定 | 既定 | 説明 |
|---|---|---|
| `SRC_FOLDER` | `""` | 空ならフォルダ選択ダイアログ。フルパスを書けば固定できる |
| `DEST_SUBFOLDER` | `"ai"` | 出力先サブフォルダ名 |
| `OVERWRITE` | `false` | `false` なら既存の`.ai`はスキップ。作り直すなら `true` |
| `EXPORT_PREVIEW_PNG` | `true` | 目視確認用PNGを書き出す |
| `AI_COMPATIBILITY` | `"ILLUSTRATOR17"` | `.ai`の互換バージョン。未対応なら自動で下位にフォールバック |
| `PDF_COMPATIBLE` | `true` | **`false` にすると Step 4 の自動照合ができなくなる**ので基本そのまま |
| `CROP_BOX` | `"PDFMEDIABOX"` | 取り込む領域。用紙が切れる場合は `"PDFCROPBOX"` 等を試す |
| `SUPPRESS_DIALOGS` | `true` | フォント置換ダイアログで止まらないようにする |

### Step 4: 変換結果の照合

```bash
python verify_ai.py --src "C:\Users\tsoma\Documents\KSD_地盤調査\柱状図_最終版"
```

（`.ai` の場所が既定の `WORK\ai` でなければ `--ai` で指定する）

`.ai` はPDF互換で保存されていればPDFとして読めるので、元PDFと突き合わせて次を見る：

- 8枚ぶんの `.ai` が出ているか（No.6は**ファイル名に「修正」が残っているか**も見る）
- 用紙サイズ・ページ数が元と一致しているか
- **文字の網羅率**（元PDFの文字が出力側にどれだけ残っているか）。98%未満で警告、90%未満でエラー
- **消えた語句**のサンプル（例: 「ローム層」が出力に無い、など）
- **文字化けの兆候**（元PDFに無い日本語文字が出力に増えていないか、U+FFFDの有無）
- 出力側の未埋め込みフォント

結果は画面と `WORK\ai\reports\verify_report.{json,md}` に出る。
自動照合はあくまで**目視で見るべき箇所を絞るためのもの**で、最後は `preview\` のPNGで
柱状図の罫線・ハッチング・記号が崩れていないかを見ること。

## フォントの扱い（ここが一番こける）

**PDFにフォントが埋め込まれていても、Illustratorで「編集可能なテキスト」として開くには、
そのフォントがPCにインストールされている必要がある。** 未インストールなら別フォントに置換され、
字送りが変わってレイアウトが崩れる（柱状図は罫線と文字位置がシビアなので影響が大きい）。

手順：

1. `preflight.py` の出力で、各PDFの使用フォント名を確認する（`preflight_report.md` に一覧が出る）
2. 同じフォントをPCに入れる。**今回の8枚は MS ゴシック / MS 明朝 / MS P明朝 のみ**だったので、
   日本語版Windowsなら追加インストールは不要（上の「実データの事前チェック結果」参照）
3. 変換後、`conversion_log_*.txt` の「使用フォント」と、`preflight_report.md` の
   フォント一覧を見比べる。名前が変わっていれば置換が起きている
4. 置換が避けられない場合は、発注者（光貴基礎コンサルタント）にフォント名を確認するか、
   その柱状図だけ文字をアウトライン化した版を別途もらう

## トラブルシューティング

| 症状 | 見るところ / 対処 |
|---|---|
| `preflight.py` で `テキストがほとんど抽出できない` | スキャン画像PDFの可能性。Illustratorで開いても文字は編集できない。ベクターPDFの再発行を依頼する |
| Illustratorで開くと文字が別フォントになる | 「フォントの扱い」参照。元フォントをインストールしてから再変換 |
| `.ai` は出たが `verify_ai.py` が「PDFとして読めない」 | `CONFIG.PDF_COMPATIBLE` が `false` になっていないか確認して再変換 |
| 用紙サイズが元と違う | `CONFIG.CROP_BOX` を `PDFCROPBOX` / `PDFARTBOX` などに変えて試す |
| 文字網羅率が低い | フォント置換か、テキストがアウトライン化された可能性。`verify_report.md` の「消えた語句」から該当箇所を特定して目視確認 |
| 変換が途中で止まる | `CONFIG.SUPPRESS_DIALOGS` を `true` に。すでに `true` ならログの最後のファイル名を見て、そのPDF単体で再現を確認 |
| 2回目以降なにも変換されない | `OVERWRITE` が `false` で既存`.ai`をスキップしている |
