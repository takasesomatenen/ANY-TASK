# BODY N BRAIN

> 4×4・16マスの2人用アブストラクト。**コマにコマを乗せると、性質が変わる。**

**BODY**（四角・縦横1マス）と **BRAIN**（丸・斜め1マス）。
どちらも単体では鈍いのに、BRAIN が BODY の上に乗ると
**8方向に2マス滑る合体駒**という、どちらの単体にも無い動きに変わります。

そして合体駒は単体の駒では取れません。代わりに **タックル** —
BODY が体当たりして、上の BRAIN だけを叩き落とせます。
落ちた先が盤外なら、その BRAIN は撃墜されて負け。
**強くなるほど、負け筋も同じ駒に集まります。**

## 遊ぶ

```bash
node build.mjs        # index.html を生成（依存パッケージなし）
open index.html       # ブラウザで開くだけ。AI対戦・2人対戦の両方あり
```

`index.html` は完全に自己完結した1ファイルです（サーバ不要・外部通信なし）。

## バランス

ルールは自己対戦で実測しながら決めました（詳細は [BALANCE.md](docs/BALANCE.md)）。

- 初版は **千日手 59%**、補正前は **先手勝率 76.7%** でした。
- 「合体駒どうしの捕獲」「侵攻勝ちは単体 BRAIN 限定」「千日手は判定で決着」「先手の初手税」の
  4点で、**引き分け 0.0% / 先手勝率 48〜53%（探索深さ4・各200局）** まで詰めました。
- 先手勝率は探索深さによって 22〜81% と振れます。偏りの向きは一貫していないため、
  真剣勝負では **スワップ（ピー・ルール）** の併用を推奨します（UIでは既定でON）。
- 深く読める側は **手番の色に関係なく 70〜89% で勝ちます**。実力が結果に出るゲームです。

```bash
node src/balance.mjs 200 4 0.15   # 現行ルールを測る
node src/sweep.mjs   60  3        # ルール24通りを総当たりで比較
```
