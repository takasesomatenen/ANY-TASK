# ゲームバランス — 実測と調整の記録

ルールは勘で決めていません。**盤サイズを含めて**、バランスに関わる要素を全て
`DEFAULT_RULES` のフラグにし、αβ探索AIどうしの自己対戦
（`src/sweep.mjs` / `src/balance.mjs`）で
**先手勝率・引き分け率・平均手数・決着理由の内訳**を測りながら詰めました。

再現方法:

```bash
node src/balance.mjs 200 4 0.15   # 現行ルールを 200局・探索深さ4 で測定
node src/sweep.mjs   40  4 size   # 盤サイズ x 合体駒の射程 x 侵攻難度
node src/sweep.mjs   40  4 rules  # メカニクスのフラグ総当たり
```

`temperature` は AI が最善手からどれだけ逸れるかの幅です。0 に近いほど強く、決定的に指します。

## 設計目標

| 指標 | 目標 |
|---|---|
| 先手勝率 | 50% 付近。しかも**探索の強さを変えても崩れない**こと |
| 引き分け率 | 低い（千日手で逃げられない） |
| 平均手数 | 40〜90手（構想が立ち、かつ終わる長さ） |
| 決着理由 | 撃破・侵攻・判定がどれも実際に出る |

## なぜ 6×6 なのか

初版は 4×4（16マス）でした。「もう少し広い方が面白いのでは」という問いに、
4×4 / 5×5 / 6×6 / 7×7 を実測して答えを出しました。

### 第1段：サイズ × 合体駒の射程 × 侵攻難度（各40局・深さ4・temp 0.2）

| 盤 | 射程 | 侵攻 | 先手勝率 | 平均手数 | 決着理由 |
|---|---|---|---|---|---|
| 5×5 | 1 | 1手守 | 27.5% | 51 | 千日手42% 侵攻53% 撃破5% |
| 5×5 | 2 | 1手守 | **50.0%** | 50 | 千日手48% 侵攻33% 撃破20% |
| 6×6 | 1 | 1手守 | 55.0% | 75 | 侵攻58% 撃破23% 千日手15% |
| **6×6** | **2** | **1手守** | **37.5%** | 94 | 侵攻55% 千日手25% 撃破10% |
| 7×7 | 1 | 1手守 | 52.5% | 62 | **侵攻88%** 撃破5% |
| 7×7 | 2 | 1手守 | 32.5% | 55 | 侵攻75% 撃破15% |

**大きければ良いわけではない**ことがはっきり出ました。7×7 では決着の 75〜88% が侵攻勝ち
──最奥段7マスを守り切れず、盤を横断する競走になってしまいます。

### 第2段：5×5 と 6×6 の決戦（各120局・深さ4）

第1段は1条件40局と少なく、誤差が大きいので上位2つを増やして再測定しました。

| 盤 | temp 0.06（強い） | temp 0.2（少し緩い） | 平均手数 |
|---|---|---|---|
| 5×5 | **先手 15.0%** | 先手 49.2% | 38〜47手 |
| **6×6** | **先手 49.2%** | **先手 45.8%** | 50〜77手 |

これが決め手でした。**5×5 は強い設定にすると先手勝率が 15% まで崩壊します**
（AIが強くなるほど要塞化し、判定で後手が勝ち続ける）。
**6×6 は 46〜49% で、探索の強さを変えても揺れません。**

→ **採用：6×6（36マス）／各6駒（BODY 5 ＋ BRAIN 1）／合体駒の射程 2。**

副次的な効果として、6×6 では中央が広く合体駒が長く生き残るので、
「合体するかどうか」の判断が 4×4 より長く効き続けます。

## 4×4 時代に潰した問題 3つ

盤を広げる前に、メカニクス側の穴は先に塞いであります。

### 問題1：合体駒どうしが噛み合わず、59% が千日手

初版は「合体駒は単体では取れない」「合体駒は合体駒を取れない」でした。
結果、終盤は必ず **塔 vs 塔の膠着**になり、盤上で何も起こらなくなりました。

**対策**：合体駒どうしの捕獲を解禁（`stackCapturesStack`）。
塔は「無敵の要塞」ではなく「置き場所を間違えたら即死する主力」になりました。

### 問題2：侵攻勝ちを合体駒に許すと、先手が100%勝つ

「BRAIN が敵陣最奥に到達したら勝ち」を素直に入れると、
合体駒が2マス滑って **8手で盤を渡り切り**、先手が勝つだけのゲームになりました（先手 92〜100%）。

**対策**：`invasion: "lone"` — **単体の BRAIN でしか侵攻勝ちできない**。
乗り込むには必ず合体を解かねばならず、その瞬間から BRAIN は誰にでも取られます。

### 問題3：千日手が「逃げ得」になっていた

**対策**：千日手・手数切れは **判定**（`judge()`）で決着させる。
侵攻度 → BODY 数 の順で比較し、後手に **コミ 0.5**。
これで引き分けは **全条件で 0.0%** になりました。

### 先手有利の打ち消し（4×4 での比較・180局）

| 補正 | 先手勝率 | 引分 |
|---|---|---|
| なし | 76.7% | 0.0% |
| コミ 1 | 70.6% | 20.6% |
| コミ 2 | 56.1% | 0.0% |
| **初手税（先手の初手は BODY 移動のみ）** | **53.3%** | **0.0%** |
| 後手が最初から合体済み | 33.3% | 0.0% |

コミだけでは足りません（千日手局の裁定しか動かせないため）。**初手税**が最も素直に効きました。
加えて **スワップ（ピー・ルール）** をUIで既定ONにしています。

## 現行ルール（6×6）の実測値

`DEFAULT_RULES`：6×6 / 合体駒2マス / 塔は塔を取れる / 侵攻は単体BRAINのみ・1手守 /
初手税あり / コミ0.5 / 120手判定

| 条件 | 局数 | 先手勝率 | 引分 | 平均手数 | 決着理由 |
|---|---|---|---|---|---|
| 深さ4 temp 0.06 | 120 | 49.2% | 0.0% | 50手 | 千日手73% 侵攻21% 撃破7% |
| 深さ4 temp 0.20 | 120 | 45.8% | 0.0% | 77手 | 侵攻54% 千日手30% 撃破12% 手数切れ4% |

### 正直な但し書き

- **引き分けは 0%**、先手勝率は **46〜49%** で安定しています。4×4 時代のように
  探索の深さで 22%〜81% と暴れることはなくなりました。
- ただし **決着の3〜7割が「判定」経由**です。深さ4の探索では 36マスの盤を破り切れず、
  押し合ったまま千日手になり、侵攻度の差で決着します。判定は「深く攻めている側が勝つ」
  ルールなので勝負としては成立していますが、**人間同士ならもっと直接的な決着が増えるはず**で、
  この数字はAIの読みの浅さも含んだものだと考えてください。
- 真剣勝負では **スワップ**の併用を推奨します（先手有利・後手有利のどちらでも構造的に消えます）。

## 調整に使えるつまみ

`src/engine.mjs` の `DEFAULT_RULES`。`src/sweep.mjs` が総当たりで測ります。

| フラグ | 現行値 | 効果 |
|---|---|---|
| `size` | 6 | 盤の一辺。各プレイヤーは `size` 枚（BRAIN 1 ＋ BODY `size-1`）を持つ |
| `stackRange` | 2 | 合体駒の滑走距離。1にすると膠着し、3以上は侵攻競走になる |
| `stackCapturesStack` | true | false にすると終盤が膠着し千日手が急増 |
| `tackle` | true | false にすると合体駒が実質無敵になる |
| `invasion` | `"lone"` | `"any"` は先手必勝、`"none"` は千日手が急増 |
| `invasionSurvive` | 1 | 侵攻勝ちに必要な「生き延びる自分の手番」の数。2 にすると侵攻が減る |
| `komi` | 0.5 | 判定時の後手ボーナス。1以上にすると後手に振れすぎる |
| `openingTax` | true | 先手有利の主な打ち消し |
| `maxPly` | 120 | 手数切れ |
