# any-task

General-purpose repo for standalone task scripts and small tools.

## Projects

- **[body-n-brain/](body-n-brain/)** — BODY N BRAIN: a 4×4 two-player abstract
  strategy game where stacking a BRAIN piece onto a BODY piece changes how the
  piece moves. Includes the rules engine, an alpha-beta AI, a playable
  single-file browser build, and a self-play harness used to tune the balance.
